# Карты контроля ЦСБ

**Статус:** в разработке  
**Версия концепции:** 0.1  
**Дата:** 19.11.2026

## Назначение
Единая библиотека технологических знаний и карт контроля для инженеров Центра сопровождения бурения (ЦСБ), осуществляющих круглосуточное сопровождение строительства скважин.

## Цель
Повышение эффективности строительства скважин посредством систематизации экспертных знаний, своевременного выявления отклонений и рисков, выявления резервов эффективности и тиражирования лучших практик.

## Задачи
- Определять технологические процессы, требующие внимания инженеров ЦСБ.
- Формировать признаки идентификации операций по диаграммам ГТИ (ДЭЛ).
- Определять этапы, контрольные точки, контролируемые параметры и критерии соответствия.
- Формировать алгоритмы действий инженеров в пределах их ответственности.
- Накапливать результаты контроля и подтвержденные лучшие практики.

## Назначение карты контроля
Карта помогает инженеру идентифицировать технологическую операцию и ее этап, определить, на чем сфокусировать внимание, сопоставить факт с требованиями плана работ, выявить отклонения, риски и резервы эффективности.

Карта не заменяет утвержденный план работ и не изменяет распределение ответственности между участниками строительства скважины.

## Методология
1. Технологический процесс и этап.
2. Признаки идентификации по ГТИ.
3. Контрольная точка.
4. Контролируемый параметр и критерий соответствия.
5. Признаки отклонения и возможные последствия.
6. Действия инженера ЦСБ.
7. Критерии эффективности, если применимы.

Критерии должны иметь источник. Подтвержденные факты, гипотезы и потенциальные риски разделяются. Карты проходят экспертную проверку и апробацию. Предыдущие разработки сохраняются в локальных архивных каталогах.

## Развитие проекта
Первый этап: карта контроля операции «Срезка с цементного моста». В дальнейшем планируется рабочий HTML-портал для инженеров ЦСБ. README.md служит документацией и навигацией по библиотеке и актуализируется по мере развития проекта.
